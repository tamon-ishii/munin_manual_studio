# Munin Manual Studio 0.8.0

原稿編集・画像管理・原稿チェックの操作を整理しました。

- フォルダ履歴を直下のドロップダウンに変更し、矢印キー・Home・End・Escapeに対応。
- 新規ワークスペース作成とワークスペース設定を画面から削除。
- 撮影するアプリの登録をリソース一覧へ移動し、呼び方を統一。
- 原稿タブ・表示切替・保存状態を同じ行に配置し、本文の表示領域を拡大。
- AI操作名で選択範囲の編集とカーソル位置への挿入を区別。
- 保存失敗時の再試行と、外部変更との競合時の比較画面を追加。
- 原稿・フォルダの作成、画像の再撮影・更新をメニューに整理。
- フォルダ・原稿未選択時の操作案内と、独立した執筆方針の編集画面を追加。
- HTML出力の画面を原稿チェックへ変更。HTML生成は既存の外部連携・CLIから実行できます。
- `manual_doc/` に日本語の利用ガイド下書きを追加。
- macOSなどでシンボリックリンクを含むプロジェクトの画像差し替え・復元が失敗する問題を修正。

配布ZIPは展開後の配置を保持して起動してください。Markdown編集・手動撮影にAI設定は不要です。AI機能には接続設定、外部からのHTML生成にはMkDocsが必要です。
