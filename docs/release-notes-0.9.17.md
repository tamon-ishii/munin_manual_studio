# Munin Manual Studio 0.9.17

Windowsの撮影・再撮影と、ソースからの起動を改善しました。

- Windowsでの対象アプリ起動、画面撮影、再撮影の処理を修正しました。
- スクリーンショット操作とエディターのコンテキストメニューを改善しました。
- MarkItsをGitサブモジュールとして管理し、起動ランチャーで未取得のソースを自動取得します。
- 旧構成のファイルを保管してからMarkItsを取得し、ビルドキャッシュを再利用します。

- Windowsの画像生成結果でドライブ文字付きパスを認識できない問題を修正しました。
- Windowsの日本語非対応の出力環境でも起動時の取得処理を継続できるようにしました。

Windows x64、Linux x64、macOS Intel／Apple Silicon向けZIPを配布します。
