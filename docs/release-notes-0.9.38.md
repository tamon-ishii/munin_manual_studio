# Munin Manual Studio 0.9.38

- **目的別の3ダイアログ再編（原稿作成支援／原稿チェック／HTML出力）**:
  - 「AI協業ツール」に混在していた機能を作業目的に合わせて整理しました。
  - **原稿作成支援**（3タブ）：「操作記録から手順書」「FAQ・要約を作成」「多言語の差分翻訳」に1タブ1機能で分離。
  - **原稿チェック**（4タブ）：従来の「品質チェック」に加え、「ソースとの裏取り」「アプリ変更の影響」「ページ構成・孤立診断」を1か所に統合。
  - **HTML出力**（3タブ）：「出力・テーマ」（サイト名入力欄を直接追加して1画面完結）、「目次順・非表示」、および日本語UIへ刷新した **「読者別出力」**（「全員共通／特定の読者に限定」切替・仕組みガイド・一括保存）を統合。
- **画面・設定・導線の全面整理**:
  - エディタの「挿入・その他」メニューから `AIメモを挿入`・`AIメモ一覧・依頼`・`AIターミナルへ送る` を実行できるようにし、エディタ上部に `原稿内検索` ボタン（`Ctrl/Cmd+F`）、専用の左右分割アイコン、状態が分かるソース表示切替ラベル、ファイルツリーのホバー `⋯` メニューを追加。
  - 上部ナビを毎日の作業順へ整理し、メイン編集パネルの誤クローズを防止、AIターミナルの未接続/エラー案内バー表示と「自動審査」への名称明確化を実施。
  - 設定ダイアログの初期タブを「外観」に変更し、「プロジェクト」タブを新設して保存先・対象アプリ・執筆方針を集約。ツールバー設定の二重チェックボックスを1行1チェックへ簡素化し、推敲スキルを説明付き折りたたみブロックへ整理、ショートカット一覧から変更画面への直接導線を追加。
  - 画像管理・サブダイアログのフッター（`キャンセル` 統一）・専門用語・フォルダー表記を全体にわたり平易化・統一しました。

配布対象は Windows x64 です。
