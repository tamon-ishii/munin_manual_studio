# Munin Manual Studio 0.9.12

原稿編集・プレビュー・画像一覧の不要な再処理を減らしました。

- 原稿の自動保存・手動保存で、非表示のリソース一覧を再取得しません。表示中の使用箇所は保存後に更新し、一覧を開いた際にも最新の状態を取得します。
- 編集のみ表示中は自動プレビューを保留します。表示を戻したときに最新の原稿を生成し、生成中の追加入力は最新内容にまとめます。プレビュー再読込は引き続き利用できます。
- サムネイルを一覧更新後も再利用します。プロジェクト・画像パス・更新情報で区別し、画像変更時は再取得します。メモリ上の保持数を制限し、撮影画像の一覧用サムネイルも縮小します。原本と採用画像は変更しません。
- 画像一覧と撮影一覧を1回の応答にまとめ、撮影画像の使用原稿はまとめて調査します。
- ディレクトリ一覧と原稿の画像参照を `.munin/cache/resources-v1/` に差分索引として保持します。変更した原稿だけ読み直し、追加・削除・移動も反映します。キャッシュが壊れている場合や保存できない環境では通常の読み取りへ戻ります。

Windows x64、Linux x64、macOS Intel／Apple Silicon向けZIPを配布します。展開後は補助実行ファイルを含めて配置を保持してください。

## 編集画面とMarkdown

- GitHub Flavored Markdownの表・タスクリスト・取り消し線・自動リンクに対応し、NOTE／TIP／IMPORTANT／WARNING／CAUTIONのアラート表示を追加しました。プレビューと公開用変換、リッチ編集で扱えます。
- MARKDOWNの専用バーを撤去し、ソース切替を既存の操作列へ移動しました。
- 保存済み表示を撤去し、未保存の原稿はタブの `*` で表示します。保存失敗時の再試行は下部に表示します。
- スクリーンショット・AIレビュー・AI修正／挿入・AI作画を上段へ移し、原稿タブの表示領域を広げました。

## ファイル移動

ファイルツリーの右クリック、またはフォルダーへのドラッグからファイルを移動できます。移動前にリンク変更を確認でき、移動する原稿の相対参照と他原稿からの参照、管理画像の関連情報を更新します。既存ファイルへの上書きや確認後に変更された内容は保護し、元データを `.munin/file-moves/` にバックアップします。フォルダー単位や別ファイルシステムへの移動は対象外です。

## スクリーンショット

撮影操作ポップアップを専用の軽量画面へ変更し、キャンセルボタンとEscキーで中止してメイン画面へ戻れるようにしました。Windowsでは画面が描画されない場合にもネイティブ側でEscを検出します。Windows実機での白画面再現検証は未実施です。

GitHubアラート用のエディタープラグインを追加し、リッチ編集・Markdownソースの両ツールバーからInfo（NOTE）・ヒント・重要・警告・注意を挿入できます。
