# Munin Manual Studio 0.9.28

- 撮影した画像を撮影リソースへ登録し、編集用メタデータを除いた文書用画像をエディタへ自動挿入するようにしました。
- 撮影リソースの画像をドラッグして文書へ挿入できます。文書用画像の識別子から元リソースを参照し、注釈を復元して再編集します。
- 撮影リソース一覧の不要な操作を削除し、編集・再撮影などの操作をツールチップ付きアイコンへ変更しました。
- Windowsのドック移動を改善し、画像のドラッグ後に挿入位置の線が残る問題を修正しました。
- 画像の表示設定でプレビューを更新し、エディタとプレビューの本文幅・余白を揃えました。設定ウィンドウの適用ボタンが切れないようにしました。
- 「Markdownソース」を、表示状態が分かるトグルボタンへ変更しました。

配布対象はWindows x64です。直近の表示設定・本文幅・トグル変更について、ローカルでの追加検証は実施していません。
