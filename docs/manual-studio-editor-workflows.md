# 原稿・画像の編集

ファイルツリーからMarkdown原稿を開くと、編集画面に原稿タブが追加されます。タブを切り替えても未保存の文章、カーソル位置、Undo履歴を保持します。未保存のタブを閉じるときは、保存・破棄・キャンセルを選べます。プロジェクト変更とアプリ終了でも未保存の原稿を確認します。

画像ファイルをクリックすると閲覧タブが開きます。「実寸表示」で拡大し、「画面に合わせる」で全体を確認できます。画像をファイルツリーから原稿へドラッグすると、既存画像への相対参照を挿入します。スクリーンショットの注釈・クロップの編集は、スクリーンショット一覧の「MarkItsで編集」から行います。

フォルダーの右クリックメニューから「Markdownを作成」「フォルダーを作成」を選ぶと、そのフォルダー内に作成します。ファイルの右クリックでは同じ階層が作成先になります。

## スクリーンショット

「文書に挿入」では原稿と位置を選択します。現在の原稿ではカーソル位置を使えます。ほかに原稿末尾・見出しを指定でき、挿入後は編集画面へ戻ります。挿入はUndo/Redoで戻せます。

各画像の「履歴・管理」には版の選択・採用・保護・共有関係・テンプレート操作があります。「共有関係」は原本を共有する派生画像と使用原稿を表示します。共有原本の再撮影は1回で、各画像の注釈・クロップを個別に適用します。

「注釈テンプレートを保存」で、選択版の注釈・クロップを保存できます。「注釈テンプレートを適用」は同じ寸法の原本に候補を作成します。原本と採用済み画像は保持されるため、MarkItsで微調整した後に候補を採用してください。

一覧上部の「その他 → 再撮影の事前診断」は撮影手順、起動パス、画像の整合性、画面環境を確認します。アプリ起動や撮影は行いません。現在の画面で操作対象を特定できるかは再生時の確認になります。

## AI作画

編集画面の「その他の文書操作（⋯）→ AI作画」から画像の指示を入力します。「作画の接続設定」で画像モデル・API URL・APIキーを設定できます。初期接続先はOpenAI画像生成APIです。文章生成の接続設定とは独立しています。

APIキーは保存しません。入力する代わりに、起動環境の `MUNIN_IMAGE_API_KEY` または `OPENAI_API_KEY` も利用できます。画像モデルとAPI URLはプロジェクトの `.munin/image-generation.json` に保存します。

生成画像は画像保存先の `generated/` に保存し、指示・モデルなどの生成情報は `.munin/generated-images/` に保持します。プレビューを確認して「原稿に挿入」を選ぶまで原稿は変更しません。接続エラー時も原稿を保持します。

接続形式は [OpenAIの画像生成API](https://developers.openai.com/api/reference/resources/images/methods/generate) に準拠します。

## 表示設定

原稿は編集後に自動保存します。保存待ちの変更はタブのファイル名末尾の「*」で表示し、保存完了時に消えます。保存中・保存失敗・外部変更との競合はヘッダに表示します。保存に失敗したときは編集内容を保持し、Ctrl/Cmd+Sで再試行できます。通常の保存ボタンはありません。

原稿名はタブに表示します。「更新」は「ショートカット」の横にあり、現在の文書のAI文章とMermaidの図を更新します。

「設定 → 外観設定 → エディタのツールバー」で表示する編集項目を選びます。設定は端末内に保持し、リッチテキストとMarkdownソースに反映します。「標準に戻す」で表示項目を復元できます。

AI文章ボックスでは生成結果のメタデータコメントを隠して本文を表示します。コメントはMarkdownに保持され、生成指示の展開・折りたたみも文書内容を変更しません。
