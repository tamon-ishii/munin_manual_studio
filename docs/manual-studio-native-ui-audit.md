## 主要機能の追加検査

2026-10-11、primary-check.mdをネイティブUIで新規作成し、ソース編集・保存、新規AI文章のDiff採用と挿入、撮影済み画像の挿入、実AIレビュー、タブを閉じて再表示、プレビュー内リンク移動、公開前チェックと各ビルド操作を実行。ユーザーのプロジェクトは変更せず、一時プロジェクトで検査した。

AI統合・撮影の回帰検査、MkDocs入力とビルドボタン検査は通過。AI統合検査で撮影済み画像挿入直後の判定が一度失敗したが、実機では成功し、変更前の再実行でも通過した。ダイアログ終了後の非同期挿入を待ってから判定するようテストを修正し、再度通過を確認した。製品の新たな動作不良とは数えない。

本接続は画像入力に非対応のため、読者レビューは画像確認0/1件と未確認理由を表示した。AI作画と画像内容の照合、実MkDocsによるHTML生成は、この検査の成功範囲には含めない。

追加検査ではPNGをOSのファイル選択画面から取り込み、リソースが2件から3件へ増えること、検索で0件になり解除すると戻ることを確認。画像AIの共通接続とCodex個別接続をそれぞれ保存し、開き直して値が残ることを確認した。

リソースから画像を挿入すると選択本文が消えるケースを実機で発見。選択範囲の先頭へ追加して本文を保持するよう、ソースとリッチ編集の共通挿入処理を修正した。全文を選択して画像を挿入しても原稿が残り、Undo/Redoができる回帰検査が通過。TypeScript、Vite、Rustビルドも通過した。修正後の実機で同じ原稿・選択範囲を使った再検証は未完了。
