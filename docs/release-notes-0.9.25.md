# Munin Manual Studio 0.9.25

- 設定を種類別のタブに整理し、ツールバー右端の「設定」から開けるようにしました。タブを切り替えてもサイズを維持し、タイトルバーのドラッグで移動できます。
- VS Code準拠の初期キー割り当てと、ショートカットの変更・保存・初期化を追加しました。行の切り取りとインデント操作も改善しました。
- MarkItsの撮影キーとカーソル撮影を設定できるようにしました。設定したキーを起動先へ明示的に渡し、別のキーへ自動変更しません。文書編集と撮影待機のキー設定は独立して扱います。
- カーソル付き撮影では、使用するキーを案内する操作ウインドウを表示し、キーで撮影してから編集画面を開きます。キー登録の失敗や競合も案内します。
- Windowsの撮影対象選択を全ディスプレイに対応させました。
- 過去のAI実行ログを開いた際、実行中ではないのに進捗バーが動く表示を修正しました。

Windows x64向けZIPを配布します。ZIP全体を展開し、`manual-studio.exe`を起動してください。
