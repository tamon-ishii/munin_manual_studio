# Munin Manual Studio 0.9.6

0.9系のUI改善をまとめた配布版です。UnixのAI CLI停止にはプロセスグループAPIを使い、macOSを含む環境で子プロセスと標準出力の待機を終了します。

- フォルダ履歴のドロップダウンとキーボード操作。
- 原稿タブ・表示切替・保存状態の集約、保存再試行と外部変更の比較。
- 撮影するアプリの登録、画像の再撮影・更新をリソース一覧に集約。
- 選択範囲のAI編集／カーソル位置へのAI挿入を操作名で区別し、リッチ編集の選択状態から同期。
- 独立した執筆方針、原稿・フォルダ作成メニュー、未選択時の案内。
- 原稿チェックの独立と、フォルダ読込時のMkDocs自動実行の削除。HTML生成は外部連携・CLIで実行できます。
- シンボリックリンクを含むプロジェクトの画像差し替え・復元を修正。
- 日本語の利用ガイド下書きを `manual_doc/` に追加。
- フォルダのパス入力欄の型とアクセシビリティ上の役割を明示。
- 実画面テストを現在のフォルダ入力欄・撮影するアプリ登録の名称と配置に更新。
- 合成の画像貼り付け・ドロップの検証では、ブラウザとエディター内部の選択位置が揃ってからイベントを送信。挿入位置・ファイル保存・Undoの検証を維持。

配布ZIPは展開後の配置を保持して起動してください。Markdown編集・手動撮影にAI設定は不要です。AI機能には接続設定、外部からのHTML生成にはMkDocsが必要です。
