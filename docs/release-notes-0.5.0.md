# Munin Manual Studio 0.5.0

スクリーンショットをAI生成から分離し、アプリ設定・画像一覧・MarkIts編集・個別／全体再撮影を独立した操作として利用できるようにした。文章とMermaidには共通のAIレビューと履歴を使用する。

- 「プロジェクト → アプリ登録」で起動パスと引数をプロジェクトごとに事前登録し、録画ごとの起動条件を保持する。
- 撮影原本を保持し、注釈・クロップをMarkItsで再編集する。採用画像と過去の編集を比較・復元できる。
- クリック先の名前と種類を記録し、再生時に現在位置を解決する。取得できない場合はクリック前の小画像をローカルで照合する。曖昧な候補は選ばず停止する。
- 入力値の反映と撮影前の見出しを確認する。再撮影中の現在タスク、待機、成功・失敗件数を表示し、終了時にStudioへ戻る。
- AI指示を折りたたみ、任意の名前と自動管理の内部IDを使用する。エディタの巨大なツールチップ、アイコン、ツールバー、プレビュー表示を改善する。
- 生成候補の確認・採用・履歴、プレビュー移動、作業領域、ターミナルを改善する。

全28段階のローカルチェック、manual-core 153件・Studio 25件のRustテストが成功。Linux Mint/X11上の実際のManual Studioで、階層の録画、画像照合を含む再撮影、MarkIts再編集、原本保持、Studio復帰、文書挿入とHTML公開を確認した。

Windows WebView2のホバー表示を100/150/200%で確認する作業とmacOS実GUIでの一連の操作確認は残っている。Linuxの実機結果やCIのビルド成功をこれらの代替としない。操作録画はLinuxではX11が必要。画像照合はOCRやAIを使用せず、外観が変わった場合は一致せず停止することがある。
