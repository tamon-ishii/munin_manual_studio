# Munin Manual Studio 0.9.22

画像の表示設定と編集画面を改善し、リリース検証を現行の操作に合わせました。

- 画像の表示幅を「指定なし」ボタンで解除できます。配置とキャプションは個別に設定できます。
- 表示幅の入力欄と「指定なし」ボタンの高さ・位置を揃えました。
- Milkdownの編集画面でスクリーンショットの管理用コメントを非表示にします。参照情報は保持し、Markdownソースでは確認できます。
- 撮影一覧は、撮影・取り込み登録した画像だけを表示します。通常画像はファイルツリー、AI生成画像は「AI作画」の履歴から扱います。
- 使用箇所の更新と競合しても、画像の採用・復元後にプレビューを更新します。
- 再撮影テストの並び順依存と、旧UIを前提にした検証を修正しました。

Windows x64、Linux x64、macOS Intel／Apple Silicon向けZIPを配布します。
