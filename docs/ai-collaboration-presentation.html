01 · Background 02 / 11

AI と人間が「兼業・協業」するときに起きる 4 つの壁

既存の Munin は部分編集・推敲・MarkIts 撮影が強力でしたが、継続的な協業運用では次の摩擦が残っていました。

1. 画像（注釈）と本文のズレ

手順の追加・並べ替えで、スクショ上の番号バッジ（①②③）や UI ボタン名と本文が乖離。CLI 接続時は画像レビューが「未確認」になる制約もありました。

2. エディタ ⇄ AIターミナルの摩擦

人間がエディタで見つけた修正点を AI ターミナルへ伝えるには手動入力が必要。逆に AI が複数ファイルを直接更新すると差分確認が煩雑でした。

3. 複数ページ横断の表記ゆれ

人間と AI が複数ページを分担すると、「フォルダー / フォルダ」や UI ボタン名の揺れ、孤立ページ、読者向けリンク不整合が紛れ込みます。

4. 更新メンテ・裏取り・派生作成の負荷

アプリ改修のたびに「どの原稿とスクショを直すべきか」の特定、仕様のソース裏取り、FAQ・英語版への差分追従が手作業になりがちでした。

03 · Feature A 04 / 11

MarkIts 注釈・UIMap × 本文の自動整合チェック

AI コストゼロ・高速・決定論的にズレを検出

  • PNG メタデータ自動読取: 文書内 PNG または管理画像の編集用 PNG から markits:annotations / markits:uimap を取得。
  • 番号バッジ照合: 画像の ①②③ と直後の説明文（次の見出し/画像まで）を比較し、説明漏れ・余剰番号・順序逆転を検出。
  • UIMap 表記ズレ照合: 注釈ターゲットの UI 要素名と本文内「」/太字/コード表記を比較し、近接ズレを警告。
  • 安全設計: コードブロック・HTML コメント内は除外。severity: "warning" のため完成版ビルド（error のみ停止）を阻害しません。

エディタ ⇄ AIターミナル双方向送信 & インライン AI メモ

エディタからの文脈付き送信（Ctrl/Cmd+Shift+T）

選択範囲・画像ホバー「AIへ相談」・原稿チェック警告・AIターミナルツールバーから 1 クリックで構造化プロンプトを送れます。

対象原稿: docs/editing-and-ai.md（行 34-41）
注意: 未保存の変更あり → active-editor で最新本文を取得
原稿修正時は MCP の preview-edit を使ってください。
指示: ショートカットの補足をソースから確認して追記
  • 既定は「入力欄に貼り付け」: Enter 自動送信はチェック時のみ。誤爆を防止。
  • 未接続時も安心: クリップボードへコピーしてターミナルパネルを案内。

執筆を止めないインライン AI メモ（Ctrl/Cmd+Shift+M）

通常 Markdown の HTML コメント <!-- ai-note: ... --> を使い、思いついた依頼を付箋のように残せます。

AIメモ 2件（行 18: Windows/macOS のキー差を表で追記…） 一覧・AIへ依頼

リッチエディタ上部に自動表示（0件時は非表示）。チェックしたメモをまとめて AI ターミナルへ一括依頼できます。

  • 公開ビルド時は自動除去: builder.rs がコードブロック外の ai-note を除去し、公開 HTML に開発メモを残しません。
  • 原稿チェックでも警告: 書き残したままの公開ミスを防止。
05 · Feature B-3 06 / 11

AI 外部変更の「確認トレー」— 複数ファイルをハンク単位で統制

AI が直接書き換えた複数ファイルも「壊さない」

  • 自動スナップショット: AI ターミナル接続時にプロジェクト内 Markdown のベースラインを .munin/terminal-snapshots/ へ記録。
  • 差分自動検知: 新規（added）・更新（modified）・削除（deleted）を検出し、ツールバーに 外部変更を確認 (N) バッジを表示。
  • ハンク単位で採用 / 元に戻す: 変更ブロックごとにチェックを外せばその箇所だけ変更前へ復元。
  • 厳格な競合・未保存保護: 書き戻し時に現在のディスク SHA-256 を照合。さらにエディタで未保存編集中のファイルは警告表示＆確定ボタンを無効化。

06 · Feature C 07 / 11

プロジェクト用語集（.munin/glossary.json）と 4 箇所自動連携

UIMap から実ボタン名をワンクリック取り込み

「設定 → 用語集」タブで正式表記・NG表記・カテゴリ（ui / term / style）・大文字小文字区別・メモを管理できます。

{
  "version": 1,
  "terms": [{
    "preferred": "撮影するアプリを登録",
    "avoid": ["アプリ登録", "対象アプリ登録"],
    "category": "ui",
    "source": "uimap",
    "note": "本文では「」で囲む"
  }]
}

管理画像・プロジェクト内 PNG の markits:uimap を走査し、未登録 UI 要素名を一括チェック登録できます。

1. 原稿チェック＋置換

コード・URL・正式表記の部分一致を除外して NG 表記を検出。1 クリック置換＋Undo 対応。

2. エディタ内 AI

部分編集・推敲（selection_ai.rs）と全体下書き（author.rs）へ関連語を自動注入。

3. MCP 公開

project-glossary ツールで AI ターミナルから検索・カテゴリ指定取得が可能。

4. Git チーム共有

プロジェクト内 JSON として保存（最大 500 件・アトミック保存）し、チームで同一ルールを運用。

07 · AI Collab Hub (Part 1) 08 / 11

「撮るだけで初稿」と「ソースで裏取り」を統合

機能 ⑤ 操作記録 → 手順書ドラフト生成

draft-from-recording

MarkIts の録画・スクリプト（markits:operation_script / operations / annotations / uimap）から操作手順の初稿を自動生成します。

## 設定の保存手順

![設定の保存手順](<assets/rec.png>)

1. 「**設定**」ボタンをクリックします。
2. `サンプル` と入力します。
3. 「**保存**」ボタンをクリックします。

**操作後の結果**: 変更が画面に反映されます。
  • AI なしでも即座に構造化生成、接続済み AI での文章整形も選択可能。
  • 既存 reviewSelection Diff 画面で確認してからカーソル位置へ挿入。

機能 ⑥ ソースコード・UIMap 根拠ファクトチェック

fact-check-manuscript

通常 Markdown 内の --flag・ファイルパス・コマンド・「」UI 表記を、対象アプリのソースコードと撮影画像の UIMap に決定論的に照合します。

08 · AI Collab Hub (Part 2) 09 / 11

運用・保守まで支える 3 つの横断ワークフロー

analyze-app-impact

アプリ変更からの影響抽出

対象アプリリポジトリの git diff と作業ツリー変更から、変更された UI 文言・識別子・ファイル名を抽出。

  • 影響を受けるマニュアルページをスコア順に表示。
  • 一致する UIMap を持つ関連撮影画像をピックアップ。
  • そのまま AI ターミナルへ更新案の作成を依頼。
project-overview

構成・読者ダッシュボード

プロジェクト全ページを俯瞰し、ページ横断の品質と読者別出し分けを管理します。

  • 孤立ページ・重複見出し・読者リンク不整合を自動診断。
  • ai:audience（user / developer / maintainer）を UI から保存。
  • 読者別 HTML 出力（MkDocs / Zensical）を直結。
translation-diff-plan

派生生成 & 多言語差分同期

完成したマニュアル資産を別フォーマット・多言語へ壊さず展開します。

  • 選択ページから FAQ / リリースノート / クイックガイド を生成。
  • 基準言語の git diff と変更見出しだけを抽出し、翻訳先ページの該当箇所のみ同期。
  • 全文再翻訳による既存訳の破壊を防止。

10 · Summary 11 / 11

「AI とつくる、壊さない」マニュアル協業サイクルが完成

人間の意図と実画面の一次情報を起点に、初稿作成・並行執筆・品質検査・更新保守までが途切れず循環します。

STEP 01

撮る・記録

MarkIts で実画面・UIMap・操作手順を記録し、用語集へ UI 名を自動取込。

STEP 02

初稿生成

操作記録から手順書ドラフトを生成し、Diff 確認のうえ安全に挿入。

STEP 03

並行執筆

ai-note 付箋と文脈送信で AI ターミナルと並走。外部変更はトレーで承認。

STEP 04

自動検査

注釈整合・用語集・ソース裏取り・構成ダッシュボードで品質を担保。

STEP 05

公開＆追従

読者別 HTML 出力・FAQ 派生生成・アプリ Git 差分追従・多言語差分同期。

すぐ使えるショートカット & 入口

  • Ctrl/Cmd+Shift+T : 選択範囲・現在位置を AI ターミナルへ文脈付き送信
  • Ctrl/Cmd+Shift+M : カーソル位置へ <!-- ai-note: ... --> を挿入
  • 設定 → 用語集 / AIターミナル → AI協業ツール / 原稿チェック

次のアクション（実デスクトップ反映）

  • ローカル環境で npm run manual:build / npm run manual:app を実行し、デスクトップバイナリへ反映。
  • 実案件プロジェクトで UIMap 用語取込・原稿チェック・AI協業ハブを試用。
