# Munin Manual Studio 0.9.31

- AIターミナルからCodexとClaude CodeにローカルMCPサーバーを接続できます。ウィンドウ一覧、画面撮影、画像検査、画像注釈などを利用できます。
- ファイルツリーに、外部で行ったファイルの追加・削除・名前変更が自動で反映されます。
- Ctrl+Sで保存しても、エディターのスクロール位置を保持します。スクロールバーは分割境界に追従します。
- 原稿内の撮影画像をドラッグすると撮影参照ごと移動します。分割表示ではエディターとプレビューで画像の大きさが揃い、移動しても表示幅と縦横比を保持します。
- プレビューのメモや警告に、日本語の見出しと種類ごとの色付きラインを表示します。「設定 → 外観」で共通アイコンを有効にすると、エディター、プレビュー、Material for MkDocsの公開出力に同じアイコンを使います。
- 設定タブの切り替えで画面の高さが変わる問題と、撮影リソース一覧の更新失敗で原稿の読み直しが止まる問題を修正しました。

配布対象は Windows x64 です。
