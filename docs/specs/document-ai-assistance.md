# 文書レビュー・AI編集・撮影指示

操作手順は [原稿・画像の編集](../manual-studio-editor-workflows.md) を参照。

- レビュー対象は文書全体または選択範囲。想定読者・目的は実行時に編集できる。
- 指摘は読者目線・校正・画像整合に分類し、正確な引用位置・理由・修正提案を持つ。実画像を送信できない場合は未確認として扱う。
- 修正案は文章生成AIの接続を利用し、選択部分だけを置き換える。選択がなければ元のカーソル位置に文章を挿入する。
- Diffの変更単位で採用・見送り、全採用・全見送り、再作成、破棄を選べる。本文変更は採用後だけで、Undo・自動保存に参加する。
- リビジョン・ページ・内容を検証し、古い結果を別の原稿へ反映しない。画像はプロジェクト内のローカル画像のみを取得する。
- 未登録アプリの起動パスと引数は、撮影指示・READMEや起動設定・実在する実行ファイル候補をまとめて一回のAI依頼で調査し、入力済みの確認画面へ進む。登録済みアプリは保存したパスと引数で起動し、登録調査のAI依頼を省略する。起動先を選び直すとAIで補完し、空白を含む引数も一つの引数として保持する。
- スクショ指示はアプリ候補の確認・登録・起動、対象ウィンドウ選択、手順確認、実撮影、MarkIts注釈候補へ進む。
- 原本、編集版、撮影手順をリソースに保持する。候補は自動採用せず、比較して採用する。再撮影は保存済みの手順と注釈を再利用する。

画像レビューの実画像入力はAPI／ローカルLLM接続で提供する。CLIや画像未対応モデルでは文章レビューと未確認表示を利用する。ネイティブ撮影はデスクトップ版で利用し、観測できない操作・注釈要素には従来の操作記録またはMarkIts手動編集を案内する。
