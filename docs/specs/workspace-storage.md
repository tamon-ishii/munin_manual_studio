# フォルダーと保存先

## 開くフォルダー

プロジェクトは、ユーザーが開いた原稿と画像を管理するフォルダーを指す。フォルダーを開くだけでは新しい原稿や、原稿用の `docs`・公開用の `manual` を作らない。

「開く」はパス入力とフォルダー選択を提供する。ネイティブの選択ダイアログは入力された既存フォルダーを開始位置とし、未入力なら現在のプロジェクトを使う。存在しないパスの場合はOS標準の開始位置へ戻す。ブラウザー開発表示ではパスを直接入力する。

## 保存先の確認と変更

上部のフォルダー名メニューから「原稿・画像の保存先」を開き、原稿フォルダー・画像保存先・HTML出力先を確認・変更できる。プロジェクト内の相対パスを指定し、`.` は開いたフォルダー自身を指す。プロジェクト外へのパスや、画像保存先と出力先の重なりは拒否する。原稿ルートが `.` の場合、内包するHTML出力先には `.munin` 内を使用する。

変更前に未保存原稿を保存・確認する。変更は設定と今後の保存先へ適用し、既存ファイル・画像参照の移動や書き換えは行わない。保存後は原稿一覧を読み直す。他の操作で保存先が変わっていた場合は上書きせず開き直しを案内する。AI接続、アプリ登録、執筆方針は保持する。

## 原稿ルートの決定

| 条件 | 原稿フォルダー | 画像フォルダー | HTML出力先 |
| --- | --- | --- | --- |
| `manual_setting.json` がある | 設定の `docs` | 設定の `assets`。省略時は原稿フォルダー内の `assets` | 設定の `output` |
| 現行設定がなく、旧 `manual/config.json` がある | 旧設定を読み込む | 旧設定を読み込む | 旧設定を読み込む |
| 設定がなく、直下にMarkdown原稿がある、または `docs` が存在しない | 開いたフォルダー自身（`.`） | `assets` | `.munin/site` |
| 設定がなく、直下にMarkdown原稿がなく、既存の `docs` がある | `docs` | `docs/assets` | `manual` |

この表は既存フォルダーを開く場合の仕様である。CLIのテンプレート作成や新規ワークスペース作成では、明示した構成と従来の初期構成を使用する。既存の画像・撮影手順を自動で移動・削除しない。設定ファイルが壊れて読み込めない場合は従来の既定設定へ戻るため、ファイルの修復が必要になる。

## 資産の所有範囲

手動撮影・録画・再撮影・注釈・クロップはMarkIts側で処理する。Munin連携では、表示画素と再編集用の原本・UIMap・注釈・クロップ・操作記録を一つのPNG内に保持し、画像保存先の `markits/<PNG全体のSHA-256>.png` に保存する。同一内容は再利用し、原本や録画を `.munin` に別途複製しない。HTML出力用コピーでは編集メタデータを除去する。旧プロジェクトとAI・CLI機能の保存先は次の表のとおり保持する。

| 保存先 | 内容 |
| --- | --- |
| 画像フォルダーの `screenshots/` | 採用済みの撮影PNG |
| 画像フォルダーの `generated/` | AI作画のPNG |
| 画像フォルダーの `edited/` | 通常画像のMarkIts編集用コピー |
| `.munin/scenarios/` | 新規作成する撮影・再生手順 |
| `.munin/screenshot-sources/` | フルサイズの撮影原本 |
| `.munin/screenshots/` | 編集版・注釈・クロップの管理情報（旧形式の編集セッションも互換保持） |
| `.munin/recaptures/` | 再撮影履歴 |
| `.munin/operation-timings.json` | 撮影・挿入・MarkIts取り込みの処理時間（直近50件） |
| `.munin/screenshot-templates/` | 注釈・クロップのテンプレート |
| `.munin/image-generation.json` | AI作画の接続設定（APIキーを除く） |
| `.munin/generated-images/` / `.munin/image-jobs/` | 作画のメタデータと実行状態 |
| `.munin/resource-replacements/` | 通常画像を差し替える前のバックアップ |
| `.munin/executions/` | 旧形式の更新記録（互換・閲覧用） |
| `.munin/brief.md` | 原稿ルートが `.` の場合の執筆方針 |
| `manual/brief.md` | 従来構成の執筆方針。既存ファイルは互換読み取り |

旧 `manual/scenarios/` の撮影手順と旧原本形式は引き続き読み込める。新規の手動撮影・撮影手順作成は `.munin/scenarios/` を使う。

旧形式の編集版の情報は `manifest.json` に保存し、同じ情報の `edits/*.json` は新規作成しない。既存の個別JSONは互換読み取りのため残す。過去にプロジェクト内へ保存されたセッションは自動削除しない。新しい撮影取り込みはMarkItsの履歴から完成画像を取り込む。既存画像の直接編集では入力画像をそのままMarkItsへ渡し、出力PNGと完了通知だけをOSの一時フォルダーに作成して処理終了時に削除する。

旧形式の撮影原本は同じ撮影から派生した画像・編集版で共有し、各編集版のPNGへ重複して埋め込まない。文書から参照するPNGは表示用の画素だけを含む。

画像参照は挿入先原稿からの相対パスとする。原稿から参照を消しても資産を削除しない。プロジェクト移動時は `.munin` も含めて保持する。公開出力には原本、注釈、操作記録などの `.munin` 内部データを含めない。設定パスはプロジェクト外へ逸脱できない。
