# 全文検索・置換とGit履歴

## 全文検索・置換

ファイルツリーの「全文検索・置換」からプロジェクト内のMarkdown本文を文字どおりに検索する。大文字・小文字の区別を選べる。結果には原稿・行・抜粋を表示し、選択するとソースの該当範囲へ移動する。日本語や絵文字を含む位置はエディタの文字位置に合わせる。

隠しフォルダー、依存パッケージ、ビルド出力、プロジェクト外へのパスを除外する。読み取り失敗と上限到達を明示する。置換対象はチェックで選び、変更前後を確認してから反映する。適用時は全対象のリビジョンを確認し、外部変更があれば一部だけを書き換えない。直前の一括置換は、後からの変更がない場合にまとめて取り消せる。

## 原稿ごとのGit履歴

原稿の「⋯ → Git履歴・復元」でGit状態、明示的な初期化、現在の原稿の履歴と比較、原稿単位のコミットを扱う。Git未導入・未設定でも通常編集は使える。フォルダーを開く操作や自動保存では初期化・コミットしない。

コミットは保存済みの選択原稿と入力された説明だけを対象にする。他ファイルの変更やステージ状態を巻き込まない。過去版の閲覧と比較ではファイルを書き換えない。確認して復元した場合は通常の編集・保存経路へ反映し、Undoを提供する。ブランチ・インデックスの巻き戻しやリモート操作は提供しない。

## 見出し機能の範囲

原稿上部に見出しアウトラインのバーを表示しない。利用ガイドでアウトラインによる移動・節の並べ替えを案内しない。見出しの書式設定は編集ツールバーに残す。バックエンドの見出し解析APIは互換機能として保持している。

操作手順は [利用ガイド](../../manual_doc/search-outline-and-git.md)、API契約は [原稿操作API](../manuscript-tools-api.md) を参照する。
