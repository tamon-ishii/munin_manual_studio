# スクリーンショット管理

撮影管理画像は [リソース一覧](resource-library.md) に表示する。この仕様は撮影原本・編集版・再撮影・採用を扱い、通常画像の差し替えとAI作画はそれぞれの仕様に従う。

撮影するアプリは、上部の「リソース一覧」の右隣にある「撮影するアプリを登録」で実行ファイル・作業フォルダ・引数を登録する。名前は省略できる。同名登録も可能で、識別情報は自動で付ける。引数は1行に1つ入力し、空白を含む値も1つの引数として起動する。作業フォルダを選ぶと起動確認と撮影時の起動に使う。空欄ならプロジェクトフォルダを使い、古い登録や撮影手順もこの既定動作を保つ。登録はプロジェクトに保存し、端末共通の登録を取り込める。録画へ保存した起動条件は設定の変更・削除に追従しない。

リソース一覧は原稿とAI接続の選択から独立している。「撮影」で登録済みアプリを選び、撮影後にMarkItsで注釈・クロップを編集する。PNGの取り込みも利用できる。撮影した原本はMarkIts起動前に永続保存する。新規登録では原稿に自動挿入しない。「文書に挿入」で選択中の原稿へ通常Markdown画像と管理用コメントを追加する。

原本は `.munin/screenshot-sources/<撮影ID>/`、編集版は `.munin/screenshots/<自動ID>/` に保存する。`manifest.json` に形式バージョン、任意名、採用版、保護状態と撮影レシピを持つ。旧形式の `originals` も読み取り可能とし、`edits` は原本識別・ハッシュ・注釈・クロップ・観測情報、`renders` は版ごとの書き出し、`sessions` はMarkIts編集の受け渡しを持つ。プロジェクト移動時は `.munin` を含めてコピーする。元画像を上書きせず、旧原本と編集版は維持する。

原稿ルート・画像フォルダー・撮影手順の配置と互換読み取りは [フォルダーと保存先](workspace-storage.md) に従う。

採用したPNGだけを設定済み画像フォルダーの `screenshots/<自動ID>.png` へ書き出す。公開PNGは画素のみを保存し、原本や注釈メタデータを埋め込まない。HTML出力へ `.munin` をコピーしない。編集状態の保存途中・取り込み再試行では同じ版を重複登録しない。外部で公開PNGを変更した場合は採用更新を拒否する。

「MarkItsで編集」は保存した原本と注釈・クロップを復元する。MarkItsの保存ではフルサイズのベース画像も保持し、クロップを後から広げられる。平坦化画像では失われた領域・編集可能な注釈は復元できないため一覧に制約を表示する。

個別の「再撮影」と「全体を再撮影」は保存した手順を順番に再生する。全体の対象は一覧の表示範囲に依存しない。保護中、手順なし、起動アプリが見つからない画像は理由を付けて対象外にする。新原本と候補を保存し、採用版は変更しない。既存注釈を同じ寸法の画面へ引き継いでも位置の再確認が必要。寸法が変わる場合はMarkItsで再編集する。

再撮影履歴は `.munin/recaptures` に保存し、成功・失敗・中断・未実行・対象外を画像ごとに記録する。履歴から成功分を繰り返さずに再試行・再開できる。採用前に画像を比較する。個別採用または成功分の採用で、同じ画像を参照する全原稿に反映する。旧版を選択・採用して戻すこともできる。

原稿から画像参照を削除しても資産は削除しない。使用文書が残る画像や保護中の画像は通常削除を拒否する。画像の保護は画像資産の採用・再撮影を制御する。

旧撮影AIタグは読み取り互換を残す。「旧撮影タグを移行」で原本あり／平坦化のみ、保護状態を確認し、原稿と画像の競合確認・バックアップ後に画像参照へ変換する。画像が欠落している候補は先に修復する。旧画像・旧実行履歴は消さず、再実行では移行済み資産を重複作成しない。旧履歴は閲覧用で、新しい再撮影の履歴とは別管理する。

## MarkIts終了から原稿への挿入

原稿の「スクリーンショット」から手動撮影した場合は、MarkItsでの保存完了と編集版の永続化後に、その画像の最新版だけを取得して挿入確認を開く。確認画面を出す前に画像一覧の全件読み込みや原稿プレビューの更新完了を待たない。候補確認を閉じた場合も保存済み画像を保持し、一覧を更新する。既存画像から挿入する場合は選択した採用版を使い、最新版へ勝手に切り替えない。

PNGの公開版は画素を含むチャンクを再圧縮せず保持し、原本の埋め込み・注釈などの非公開メタデータを除く。MarkItsの終了確認は200ms間隔で行う。この間隔は全処理の所要時間を保証する値ではない。画像の永続化、原稿の所有者確認、失敗時の再試行と原本保持は省略しない。

保存完了を検知したら、取り込みを開始する前にStudioへ戻して「編集結果を保存中」を表示する。取り込みの原本読み取り・メタデータ読み取り・編集版登録と、原稿から挿入するまでの各工程を計測する。記録失敗は画像保存や挿入の成功を取り消さない。記録の確認方法は [画面と操作](manual-studio-ui.md) に従う。
