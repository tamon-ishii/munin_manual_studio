# 原稿作成・公開の契約

## 原稿とAI支援

原稿は通常のMarkdownで保存する。AIタグの作成・確定・自動更新・一括タグ生成は現行機能に含めない。旧タグの原稿を開く際は表示可能な本文を通常の文章として扱い、開くだけではファイルを書き換えない。明示的な保存では旧AIメタデータを除去する。旧撮影の移行は [スクリーンショット管理](screenshot-library.md) に従う。

AIレビューは原稿を変更しない。AIによる選択範囲の変更・カーソル位置への挿入は候補のDiffを確認し、採用した変更だけを反映する。Mermaid候補は反映前に構文を確認する。中断・失敗・破棄・対象の変更では原稿を保持する。契約は [文書AI支援](document-ai-assistance.md) と [画面と操作](manual-studio-ui.md) に従う。

## 撮影と画像

撮影・再撮影は画像資産に保存した手順を実行する。AI撮影指示は手順と注釈の候補作成を支援し、その後の再撮影にAIを要求しない。原本と候補を保持し、採用画像の変更には明示的な採用を必要とする。文書AI編集は撮影履歴を巻き戻さない。

## 公開前チェック

ローカルリンク切れ、Markdown見出し参照切れ、画像の欠落・不正を報告する。完成版ビルドは問題があると停止し、既存の出力を維持する。下書きビルドは問題を残したまま作成できる。外部URLの疎通は検査しない。AI接続や旧タグの生成・確定状態を公開条件にしない。

各問題には対象原稿と、特定できる場合は行番号・ソース位置を付ける。「該当箇所を開く」はMarkdownソースの対象参照へ移動する。同じ参照が複数あっても報告した位置を優先し、位置を特定できなければ原稿の先頭へ移動する。移動で原稿を書き換えない。

## 原本保持と公開画像

失敗した再撮影でも既存の有効な採用画像は公開できる。採用PNGは画素のみとし、原本・編集履歴・操作記録を公開出力へ含めない。原稿から参照を消しても画像資産を削除しない。旧撮影履歴は移行・閲覧のため保持する。
