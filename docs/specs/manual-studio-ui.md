# Manual Studio の画面と操作

## 共通の操作部品

線画アイコンは `uiIcons.ts` に定義し、24×24の座標系、20px表示、1.8の線幅、塗りなしで描画する。ファイルツリー内だけ14pxとする。戻る・進む・再読込、Undo/Redoには文字記号を使わず、同じSVGを使う。ボタンには操作名、キーボードフォーカス、無効状態を付ける。Milkdownのテーマに線画の塗りを上書きさせない。

よく使う書式、Undo/Redo、画像・リンク・表を常時表示する。使用頻度の低い挿入操作は「挿入・その他」にまとめ、項目がなくなったグループは区切り線も含めて除去する。

## 編集とプレビュー

文書名の近くに、未保存・保存中・保存済み・保存失敗を表示する。保存失敗の詳細は状態表示の説明と画面下部に表示し、未保存の内容を保持する。別の文書やプロジェクトへ移動した後に届いた保存結果は反映しない。

プレビューには現在の原稿パス、読み込み中・表示成功・表示失敗を表示する。再読込ボタンは原稿未選択時や読み込み中に無効とする。Markdownリンクは編集対象も切り替え、未保存の確認がキャンセルされた場合は移動履歴を進めない。

## AI更新

生成中、レビュー待ち、撮影中、採用済み、一部未完了、中断、更新前へ復元済みを表示する。レビュー待ちは採用して保存するまで原稿を変更しない。

部分失敗の確認画面と実行記録に成功・失敗・未完了の件数を表示する。成功分の保持と文書・画像の復元を選べる。実行結果には再実行の入口を設け、実行記録の再開計画に従って成功済みの処理を除外する。再実行でも入力確認を省略しない。復元済みの実行を再開するときは更新をやり直す。

認証、接続、応答形式、制限時間の失敗には次の操作を案内する。設定先は「設定 → AI・撮影設定」と表記する。

## 撮影画像

AIタグ一覧の撮影画像はマウスとキーボードで拡大できる。実行記録の同じ画像パスに撮影前後の画像があれば横に並べ、比較画面で同じ倍率を適用する。画像サイズ、注釈データの有無、撮影前後の注釈データが同じかどうかを表示する。狭い画面では縦に並べる。幅に合わせた表示と実寸表示を切り替え、25〜200%で拡大・縮小できる。画像が存在しない側を架空の画像で補わない。

## 設定と初回案内

「ワークスペース設定」は原稿、画像、HTML出力先を扱う。「設定 → AI・撮影設定」は接続方式と撮影コマンドを、「設定 → 外観設定」は文字サイズとテーマを扱う。

AI未設定のワークスペースでも編集・保存・プレビューを利用できる。短い使い方の案内からAI設定を開ける。案内の非表示はワークスペースごとに保存する。

## キーボード操作

Ctrl/Cmd+Sで保存、ZでUndo、Shift+ZでRedo。Windows/LinuxではCtrl+Yも使える。Ctrl/Cmd+Shift+Pで編集のみ・左右比較・プレビューのみを順に切り替え、Shift+Rでプレビューを再読込し、Shift+GでAI更新の入力確認を開く。書式はCtrl/Cmd+B・I・Kを使う。

IME変換中、キーの連続入力、ダイアログ、AIターミナル、文書以外の入力欄では文書操作のショートカットを実行しない。プレビュー内のキーボード操作にも保存・表示切替・再読込を適用する。
