# Manual Studio の画面と操作

## 画面構成

上部は最近開いたフォルダの選択・開くと、AI設定・外観・表示を扱う。フォルダー名のメニューに最近開いたフォルダー、原稿・画像の保存先、撮影・挿入の処理時間を置く。従来のワークスペース一括設定ダイアログは設けない。画面は「原稿を編集」「リソース一覧」「原稿チェック」を入口とする。HTML出力はこのUIでは扱わず、既存のバックエンド・CLIを外部連携から利用する。AIタグ一覧と画面一覧／UIMapは設けない。

「撮影するアプリを登録」は上部ナビゲーションの「リソース一覧」の右隣に置き、原稿編集中も開けるようにする。プロジェクト未選択時は無効にする。原稿タブ・原稿操作・表示切替・保存状態を同じ行にまとめ、書式は編集領域内に置く。見出しアウトラインのバーは設けず、空の書式バーも編集領域の高さを消費しない。編集とプレビューを並べる表示名は「編集＋プレビュー」、画像を生成する操作名は「AI作画」に統一する。

原稿には文書タブ、編集／分割／プレビューの表示切替、AIレビュー、AIで修正・挿入、スクリーンショット、AI作画を置く。画像の表示設定、ショートカット、読み直しと別ウィンドウ編集は「⋯」へまとめる。ボタンのアイコンと操作名を併記し、表示切替・原稿操作をグループとして区別する。狭いペインでは折り返し、操作名を省略しない。

よく使う書式、Undo/Redo、画像・リンク・表は常時表示する。コードやMermaidなどの補助操作は「挿入・その他」にまとめる。書式ツールバーの表示設定は原稿内容に影響しない。

## 保存とプレビュー

原稿は入力後の待機時と文書操作前に自動保存する。未保存はタブ名の `*`、保存中・失敗は状態表示で示す。保存失敗や外部変更との競合では編集中の内容を保持する。文書・プロジェクトを切り替えた後の古い結果を新しい対象へ適用しない。

プレビューには原稿パスと読み込み状態を表示する。原稿未選択・読み込み中は再読込を無効にする。Markdownリンクで編集対象も切り替え、移動をキャンセルした場合は履歴を進めない。

## AIレビューと変更確認

「AIレビュー」は対象範囲と想定読者を確認して実行し、原稿を変更しない。結果では読者目線・校正・画像と説明を分類し、重要度、理由、引用、改善案を区別する。分類で絞り込み、該当箇所へ移動、修正案作成、見送りを選べる。分類に指摘がない場合も明示する。画像確認数と未確認の理由を表示する。

「AIで修正・挿入」は選択範囲を変更し、選択がなければカーソル位置に新しい文章を挿入する。候補はDiff画面で確認する。変更前後を並べ、変更ごとの採用チェックと採用件数を表示する。変更のない文章は一つの折りたたみ欄にまとめる。全採用・全見送り・指示を付けた再作成・破棄を用意し、反映操作を主ボタンにする。採用した変更はUndoと保存の対象になる。

詳細な契約は [文書AI支援](document-ai-assistance.md) に従う。処理中は進捗と中断操作を示し、失敗・中断・古い応答では原稿を変更しない。

## 画像と撮影

原稿の「スクリーンショット」は現在のカーソル位置を保持し、「手動で撮影」「AIに撮影を指示」「撮影済み画像を選ぶ」から方法を選ぶ。どの方法も画像候補を確認してその位置へ挿入する。手動撮影は登録済みアプリの操作記録・実撮影・MarkIts編集を利用し、AI設定を要求しない。撮影済み画像は採用済みの版から選び、未採用候補を自動採用しない。選択中の文章は置き換えない。候補を閉じた場合や原稿が変わった場合も、撮影画像はリソース一覧に残す。

画像は [リソース一覧](resource-library.md) から管理する。AI撮影指示はアプリ登録・起動・撮影手順確認・実撮影・注釈候補作成へ進む。候補は比較してから採用する。手動操作記録・再撮影・MarkIts編集はAIなしで利用できる。原本・注釈・クロップ・撮影手順を保持する。詳細は [スクリーンショット管理](screenshot-library.md) と [AI画像生成](ai-image-generation.md) に従う。

## 用語

撮影対象を指す表記は「撮影するアプリ」に統一する。登録操作の名称は「撮影するアプリを登録」とする。

## 設定とキーボード

原稿ルートと画像・HTML出力先は [フォルダーと保存先](workspace-storage.md) に従う。AI設定は文章生成と画像生成を分け、画像には別の接続または文章と同じ接続を選べる。対象アプリの登録はプロジェクトに保存し、端末共通の登録を取り込める。外観は文字サイズ・テーマを扱う。

Ctrl/Cmd+Sは保存、ZはUndo、Shift+ZはRedo、Windows/LinuxのCtrl+YもRedo。Ctrl/Cmd+Shift+Pは表示切替、Shift+Rはプレビュー再読込、Shift+GはAI文書作成。書式はCtrl/Cmd+B・I・K。

IME変換中、キーの連続入力、ダイアログ、AIターミナル、文書以外の入力欄では文書操作を実行しない。ダイアログは画面内の幅・高さに制限し、長い内容は縦スクロールする。ボタンには操作名・フォーカス・無効状態を提供する。

## フォルダ選択と未選択時の案内

フォルダ名の下向き三角から直下に最近開いたフォルダを表示する。現在のフォルダにチェックと選択状態を付け、パスを補足表示する。上下矢印・Home・Endで移動、Enterで選択、Escapeで閉じる。外側を押した場合も閉じる。原稿未選択時は中央で原稿選択・作成を案内し、フォルダ未選択時はフォルダを開く操作を案内する。

ファイルツリーの作成操作は「＋ 作成」にまとめ、原稿とフォルダを選べる。既存の右クリックによる作成も維持する。

## AI対象・執筆方針・保存失敗

AI操作は選択範囲がある場合「選択範囲をAIで編集」、ない場合「AIで文章を挿入」とする。指示画面で対象を確認して候補を作成する。「執筆方針」は原稿編集から開き、読者・目的・操作を編集する。AI接続設定とは独立した画面で既存のプロジェクト方針を保存する。

保存状態は控えめに表示し、保存失敗時には再試行を表示する。外部変更との競合時は編集中の内容を保持し、保存先と比較する「変更を確認」を表示する。比較を開くだけでは内容・リビジョンを変更しない。保存先の読み直しは既存の未保存確認を経由する。

リソース一覧の撮影・AI撮影・読み込み・AI作画は直接操作でき、再撮影・更新は「管理」にまとめる。

「フォルダーを選ぶ」の開始位置はパス欄の既存フォルダーとし、未入力時は現在のプロジェクトを使う。全文検索・Git履歴と見出し機能の範囲は [全文検索・置換とGit履歴](manuscript-search-and-git.md) に従う。

## 撮影の進捗と処理時間

原稿からの撮影・挿入中だけ、現在の工程と工程開始からの経過秒数を表示する。アプリ操作、撮影、MarkIts編集、編集結果の保存、挿入準備、確認、原稿保存、表示更新を区別する。取り込みに失敗した場合は編集結果の保持と再確認を案内する。完了・取消・失敗時は進捗表示を終了し、別プロジェクトには表示しない。

フォルダー名メニューの「撮影・挿入の処理時間」では成功・取消・失敗別の記録と、各工程の所要時間を確認できる。アプリ操作・MarkItsでの編集と保存・挿入確認は操作待ちに含め、Studio側の処理時間と区別する。本文・画像・指示・APIキーは記録しない。
