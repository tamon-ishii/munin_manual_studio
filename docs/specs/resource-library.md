# リソース一覧

## 対象と表示

プロジェクト内の撮影管理画像・AI生成画像・その他の画像を一つの一覧に表示する。画面名は「リソース一覧」とする。原稿未選択・AI未設定でも閲覧と撮影管理を利用できる。

種類は「撮影画像」「AI生成画像」「取り込み画像」の3区分。撮影手順のない管理画像も取り込み画像に分類するが、撮影管理の履歴・採用操作を保持する。通常のプロジェクト画像も取り込み画像に含む。同じパスの画像は重複表示しない。

PNG・JPEG・GIF・WebP・SVGを一覧と閲覧の対象にする。隠しディレクトリと `node_modules`、`target`、`dist`、`__pycache__`、`site` は通常の画像探索から除外する。管理情報にある欠落画像は欠落状態で表示する。画像の読み込み上限は32,000,000バイト。形式によって閲覧できても編集・差し替えできない場合がある。

名前・パス・使用原稿の検索、種類、使用中／未使用のフィルターを併用できる。サムネイルは表示領域付近から順に取得し、一覧取得時に全画像を読み込まない。

## 使用箇所と挿入

使用箇所はプロジェクト内の保存済みMarkdownのローカル画像参照から取得する。公開対象外のMarkdownも対象とし、コード例内の画像記法を使用箇所と数えない。未保存の編集内容は一覧の使用数に含めない。

使用箇所を押すと対象原稿を開き、Markdownソースの画像記法を選択する。原稿と行番号を表示する。「文書に挿入」は挿入先原稿とカーソル位置・末尾・見出しを選び、相対画像参照を挿入する。挿入はUndo/Redoと保存の対象になる。

一覧の画像をリッチテキストまたはMarkdownソースへドラッグ＆ドロップして挿入できる。既存画像への相対参照を使い、画像ファイルを複製しない。撮影管理画像では管理用コメントも保持する。他プロジェクトの画像や、原稿未選択・画像閲覧中・処理中のドロップは拒否する。リッチテキストではドロップ位置、ソースでは現在の選択位置に挿入する。原稿が隠れている場合は「原稿を編集」にドラッグを重ねると表示する。新しく開くリソース一覧は左側のタブグループを優先し、原稿と並べて利用できる。

## 編集と差し替え

| 操作 | 結果 |
| --- | --- |
| 画像を表示 | 閲覧タブを開く |
| 通常画像をMarkItsで編集 | 編集用PNGコピーを作り、元画像を保持する |
| 撮影管理画像をMarkItsで編集 | 保存した原本・注釈・クロップから編集する |
| AIで修正 | 元画像を参照した新しい生成候補を作る |
| 差し替えと影響確認 | 同じ画像パスの内容を更新し、そのパスを参照する全原稿へ反映する |

差し替え前に候補画像と最新の使用箇所を表示する。元画像のSHA-256を確認時と実行時で照合し、外部変更があれば拒否する。元画像は `.munin/resource-replacements/` にバックアップしてから更新する。原稿本文と参照パスは書き換えない。差し替え先はPNGまたはJPEGで、候補は画像デコーダーが読み込める必要がある。

撮影管理画像は通常の差し替えを拒否し、撮影履歴から候補を比較・採用する。一覧の検索範囲は「全体を再撮影」の対象範囲を変更しない。

## 差し替えの復元

通常画像の「履歴・管理 → 前回の差し替えを戻す」から直前の未復元の差し替えを戻せる。差し替え履歴のJSONには対象パス・バックアップパス・変更前後のSHA-256・状態・日時を保存する。復元は全使用原稿へ反映されることを管理欄に表示し、原稿本文は書き換えない。

現在の画像が記録した差し替え後のハッシュと異なる場合、またはバックアップが欠落・変更されている場合は復元を拒否する。正常な復元後もバックアップを保持し、同じ履歴を二重に復元しない。撮影管理画像は従来どおり採用版の選択で戻す。履歴JSONのない旧バックアップは自動で対象画像に関連付けない。

## 原稿内の画像の表示と置換

画像の表示設定は本文幅に対する1〜100％の幅、左・中央・右の配置、任意のキャプションを扱う。設定を変更した画像は `figure[data-munin-image]` としてMarkdownに保存し、リッチテキスト、プレビュー、公開で同じ設定を使う。キャプションと代替テキストは別に保持し、文字列をHTMLエスケープする。通常のMarkdown画像は設定を変更するまで従来の記法を保持する。

リソースを原稿内の画像の上にドロップすると、その画像参照のみを置き換える。ソースではカーソルまたは選択範囲が画像記法内にある場合に置換する。説明・代替テキスト・表示設定・原稿内の位置を保持し、元ファイルを上書きしない。撮影管理画像へ置換する場合は管理用コメントを関連付け、通常画像へ置換する場合は古い撮影の関連付けを除く。設定と置換はUndo/Redo・自動保存の対象となる。
