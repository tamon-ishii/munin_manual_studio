# Munin Manual Studio 0.8.1

0.8.0で準備したUI改善を含む配布版です。フォルダを開くだけでMkDocsを自動実行する処理を外し、原稿の読込とHTML生成を分離しました。HTML生成は外部連携・CLIで明示的に実行してください。

UI改善の詳細は [0.8.0の変更内容](https://github.com/tamon-ishii/munin_manual_studio/blob/0.8.1/docs/release-notes-0.8.0.md) を参照してください。フォルダ履歴、AI編集対象の表示、保存失敗・競合への対処、執筆方針、リソース管理、原稿チェックを整理しています。

0.8.0のリリースCIはLinuxのリソース一覧検証で停止し、配布版は公開していません。0.8.1では、状態読込が公開出力を新規作成・上書きしないことを回帰テストで確認します。
