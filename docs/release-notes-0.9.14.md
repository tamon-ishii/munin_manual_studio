# Munin Manual Studio 0.9.14

原稿編集とファイル移動の操作を改善しました。

- 編集画面上部の「使い方」バーを削除しました。
- 「GitHubアラート」の表示名を「注釈」に変更しました。
- プロジェクト直下で右クリックからフォルダーを作成できない問題を修正しました。
- ファイル移動時の差分確認を省き、「移動してリンクを更新」で移動とリンク更新を実行します。
- ドラッグ中のファイルを薄く表示し、移動先フォルダーに枠と「ここへ移動」を表示します。
- 原稿は保存ボタンまたは Ctrl/Cmd+S で保存します。未保存の編集内容はタブ切り替え後も保持します。
- リッチ編集・Markdownソース・タブ切り替え時のUndo履歴と、画像挿入の取り消しを改善しました。

Windows x64、Linux x64、macOS Intel／Apple Silicon向けZIPを配布します。
