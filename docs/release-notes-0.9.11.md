# Munin Manual Studio 0.9.11

撮影対象アプリの起動設定、文書保存の内部構成、操作案内を改善しました。

- 撮影するアプリごとに作業フォルダを登録できます。起動確認、操作記録、AI撮影、保存した手順の再実行に引き継ぎます。省略時はプロジェクトフォルダを使います。
- 文書保存を専用モジュールに分離しました。同時保存の直列化、保存中の追加入力の保持、別文書・別プロジェクトへの切り替え後の応答の除外、失敗後の再試行を回帰テストで確認します。
- READMEと操作ガイドを現行UIの「AIレビュー」「AIで修正・挿入」「AI設定」「AI作画」に合わせました。AI作画設定の自動保存と、外部連携・CLIによるHTML出力の手順を明確にしました。
- 初回のプロジェクト案内から、上部の「AI設定 → 文章・図の生成」へ進めるよう案内文を修正しました。

配布ZIPは展開後の配置を保持して起動してください。Markdown編集・手動撮影にAI設定は不要です。AI機能には接続設定、HTML出力にはPythonとMkDocsが必要です。
