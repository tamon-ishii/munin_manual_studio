# Munin Manual Studio 0.9.29

- 撮影リソース一覧から、元画像・編集データ・再撮影候補を削除できます。文書用画像は保持します。
- 操作記録がなくても、撮影先ウィンドウの情報があれば再撮影できます。操作記録を使った再撮影では、撮影結果を Manual Studio に返す処理を修正しました。
- 撮影サイズが同じ場合は、切り抜きと注釈を引き継いで文書用画像を自動更新します。撮影サイズが変わった場合は候補として確認できます。
- 組み込みの MarkIts を更新し、キャプチャ画面のボタンにアイコンを追加しました。
- ドックと Markdown／プレビュー間の分割バーを細い境界線に統一しました。

配布対象は Windows x64 です。
