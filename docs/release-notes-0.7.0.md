# Munin Manual Studio 0.7.0

## 画像挿入・リソース管理の統合 (P03 / P04 / P11)

- リソースカード（通常画像・生成画像・撮影画像）、作画ダイアログ、スクショライブラリからの「文書に挿入」において、選択した原稿と位置をプロジェクトごとに保持し、次回開いた際や失敗再試行時に復元。
- 開いている原稿では「現在のカーソル位置」を最優先の既定値とし、別原稿への切り替えや失敗・キャンセル後も直前の選択先を保持。
- 「撮影済み画像を選ぶ」ダイアログで前回選択した画像IDを先頭に表示・案内。
- 10系統の画像挿入ルートで実ファイル・原本不変・Undo復帰を検証。

## AI処理ライフサイクルとプログレスの一元化 (P12)

- 文章生成、AIレビュー・校正、AI撮影、画像生成の進行状態・待機時間・ポーリング・ログ管理を `AiProgressManager` に一元化。
- 待機時間が長引いた場合の通知メッセージ更新（15秒経過判定）と、コンパクト表示（バックグラウンド化）への切替を改善。
- 中断（キャンセル）時の二重送信防止と、中断後の原稿保護・再実行保証を統一。

## 設定UIの再試行・保存契約の統一 (P13)

- 画像生成AI設定に再試行ボタンを追加し、通信失敗・保存失敗時に入力内容を保持したまま再試行できる契約を文章生成AI設定と整合。
- テキストAI接続設定と画像生成AI設定の連動・フォールバックを整理。

## 検証と品質ゲート

- UIインベントリ台帳・操作登録ゲート（695操作点・111ケース）の全項目合格。
- Linux実OS上でのネイティブGTKキャプチャ、MarkIts連携、X11クリップボードビットマップ取り込み・Undo・復帰を検証。
- PlaywrightによるブラウザUI自動テストスイート全ステージ通過。
