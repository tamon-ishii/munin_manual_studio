# 原稿・画像編集の確認（2026-10-10）

## 実装と修正

複数原稿タブ、画像閲覧タブ、ファイルツリーの右クリック作成と画像ドラッグ挿入、画像の挿入先選択、共有関係、再撮影の事前診断、注釈テンプレート、AI文章内のメタデータ非表示、AI作画、ツールバー設定を追加した。

画像タブを開いた際、既存のエディタ表示CSSが画像用の切り替え指定に優先していたため、画像の表示領域が不足していた。編集画面の指定を修正し、画像タブに150pxを超える実表示領域があり、背後の原稿エディタが非表示になることを検証した。

保存済み原稿を再選択した際はディスク上の変更を読み込む。未保存原稿はタブの下書きを保持する。「再読み込み」は未保存確認を通して実際にファイルを読み直す。切り替え後のUndo/Redo、未保存タブを閉じる際の取消と保存、外部更新の読み込みを検証した。

クロップ付きテンプレートはMarkItsの `offset_x`・`offset_y` とシーンの表示寸法を使う。適用後の寸法・シーン・原本ハッシュ・採用版保持と保護画像への適用拒否をRustテストで確認した。
