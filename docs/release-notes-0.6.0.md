# Munin Manual Studio 0.6.0 リリース準備

公開前の原稿。バージョン更新・タグ作成・配布ファイル公開は未実施。

## 編集

- 複数のMarkdown原稿をタブで開き、編集履歴・選択位置・スクロール位置を保持。
- 原稿を自動保存。未保存の変更はタブ末尾の「*」に表示し、保存失敗・競合時は編集内容を保持。Ctrl/Cmd+Sで再試行可能。
- 保存ボタンと原稿名の重複表示を除き、「更新」をショートカット横へ移動。
- 画像をタブで閲覧し、ファイルツリーから原稿へドラッグして挿入。
- ファイルツリーの右クリックからフォルダー・Markdown原稿を作成。
- ツールバーの表示項目を設定。AI文章ボックス内の生成メタデータコメントを非表示。
- AI作画の接続設定、生成プレビュー、画像保存と明示的な原稿挿入を追加。

## スクリーンショットと表示

- 原稿・見出し・末尾・カーソル位置を選んで画像を挿入。
- 原本を共有する注釈画像の関係を確認し、注釈・クロップのテンプレートを再利用。
- 再撮影の事前診断と、実行中のタスク・完了結果を表示。
- AI指示の開閉表示を明確にし、長文入力欄の高さを制限。
- 編集パネル全文がツールチップへ入る誤設定を修正。
- ダイアログの画面内配置と、小さい画面でのスクロールを改善。
