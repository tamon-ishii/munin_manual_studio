# Munin Manual Studio 0.9.36

- **出力HTMLのビジュアルテーマカスタマイズを追加**: 「HTML出力」ダイアログと「設定 → HTML出力」で、6種類のビジュアルプリセット（クリーンブルー／フォレスト／ウォームペーパー／インディゴテック／スレートダーク／ミッドナイトグリーン）をミニチュアプレビュー付きで選択でき、ライブプレビューを確認しながら配色モード・フォント・レイアウト幅・5色の詳細カスタマイズを行えるようにしました。単一HTML・MkDocs・Zensical のすべてにテーマ設定を反映し、MkDocs / Zensical 向けの3カラム `.md-grid` 幅とサイドバー配色も最適化しています。
- **HTML出力ダイアログの整理**: 不要な「HTMLを開く」ボタンを削除し、出力先・未使用画像除外・出力テーマを一括保存する「設定を保存」ボタンと「HTMLを作成」ボタンに整理しました。
- **UI 全体の改善と磨き込み**:
  - ヘッダー・ナビゲーションバーのスリム化、アイコンの SVG 統一、通知トーストの右上配置、Mermaid 図のダークモード対応、未定義テーマトークンの解消を実施しました。
  - 原稿アウトラインパネル、ショートカット一覧ダイアログ（`Ctrl/Cmd+/`）、上部バーからの「AI連携ハブ」起動、空状態での最近のプロジェクト一覧、リッチ編集フッターの文字数・カーソル・モード表示、リッチ／ソース両対応のドキュメント内検索・置換（`Ctrl/Cmd+F`・`Ctrl/Cmd+H`）、同名タブの親ディレクトリ区別表示を追加しました。
  - 撮影リソース・アセット整理（選択チェックボックス対応）・AIターミナル・フローティングメニューのはみ出し防止・設定ダイアログの保存モード表示を改善し、スタイルシートをモジュール分割しました。

配布対象は Windows x64 です。
