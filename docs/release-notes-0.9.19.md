# Munin Manual Studio 0.9.19

スクリーンショットの操作履歴と挿入フローを改善しました。

- 撮影ポップアップ下に操作履歴を表示します。クリック、文字入力、キー操作、スクロールを時刻付きで録画順に確認できます。
- 操作履歴は自動更新し、連続した文字入力をまとめて最新100件を表示します。過去の項目を読んでいる間はスクロール位置を保ちます。
- 撮影ポップアップ自身のクリックは履歴から除外します。
- スクリーンショット挿入時の最後の確認ダイアログを削除しました。手動撮影はMarkItsで編集終了後、AI撮影と撮影済み画像の選択も完了後に、元のカーソル位置へそのまま挿入します。
- 挿入のUndoと、処理中に原稿が変わった場合の挿入防止を維持します。

Windows x64、Linux x64、macOS Intel／Apple Silicon向けZIPを配布します。
