# Munin Manual Studio 0.9.10

撮影から原稿への挿入を高速化し、保存先と待ち時間を確認できるようにした配布版です。

- 撮影・MarkIts取り込み・挿入・保存の進捗と経過時間を表示。
- フォルダー名メニューに「原稿・画像の保存先」と「撮影・挿入の処理時間」を追加。直近50件を工程別に確認可能。
- MarkIts終了後の一覧全件読み込みとPNG再圧縮を省き、挿入候補の表示を高速化。
- ドキュメントフォルダー直下の原稿に対応し、不要な `docs`・`manual` の新規作成を抑制。画像は `assets`、新しい撮影手順は `.munin/scenarios` に保存。
- 「撮影するアプリを登録」を上部の「リソース一覧」の右隣へ移動。
- フォルダー選択の開始位置に、指定した既存パスを使用。
- 見出しアウトラインと空の書式バーを除去し、原稿編集領域を拡大。
- 非表示エディタの同期、画像キャッシュ、タブ描画を改善。
- 現行仕様、保存先のルール、利用ガイドを整理。

保存先を変更しても既存ファイルは移動しません。既存の明示的な設定、旧撮影手順、画像原本と編集履歴は保持します。プロジェクト移動時は `.munin` も含めてコピーしてください。

配布ZIPは展開後の配置を保持して起動してください。Markdown編集・手動撮影にAI設定は不要です。AI機能には接続設定、外部からのHTML生成にはMkDocsが必要です。
