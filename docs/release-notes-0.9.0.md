# Munin Manual Studio 0.9.0

原稿編集・画像管理・原稿チェックのUIを整理したマイナーリリースです。

- フォルダ履歴をドロップダウン化し、キーボード操作に対応。
- 新規ワークスペース作成とワークスペース設定を画面から削除。
- 撮影するアプリの登録をリソース一覧へ移動。
- 原稿タブ・表示切替・保存状態を同じ行にまとめ、本文の表示領域を拡大。
- 選択範囲のAI編集とカーソル位置へのAI挿入を操作名で区別。
- 保存失敗の再試行、外部変更との競合を比較する画面を追加。
- 原稿・フォルダ作成、画像の再撮影・更新をメニューに整理。
- 未選択時の案内と、独立した執筆方針の編集画面を追加。
- HTML出力の画面を原稿チェックへ変更し、フォルダ読込時のMkDocs自動実行も削除。HTML生成は外部連携・CLIで明示的に実行できます。
- `manual_doc/` に日本語の利用ガイド下書きを追加。
- macOSなどでシンボリックリンクを含むプロジェクトの画像差し替え・復元が失敗する問題を修正。
- 画像貼り付け・ドロップの再試行テストで、実行ごとに同じ本文位置を選択し、最新の画面座標を使うよう修正。画像位置・ファイル保存・Undoの検証は維持。

配布ZIPは展開後の配置を保持して起動してください。Markdown編集・手動撮影にAI設定は不要です。AI機能には接続設定、外部からのHTML生成にはMkDocsが必要です。
