# Munin Manual Studio 0.9.35

- **「アセットの整理」ダイアログを追加**: 上部バーの「AIで雛形作成」を「アセットの整理」へ置き換え、プロジェクト内の画像アセット一覧（サムネイル・サイズ・使用箇所リンク・使用中／未使用フィルター・検索）と、未使用アセットの一括／個別削除機能（未保存原稿の安全チェックおよび `.munin/file-deletions/` への自動バックアップ付き）を追加しました。
- **Base64 貼り付け画像の MarkIts 再編集とファイル保存**: 貼り付け済みの Base64 画像（`data:image/...`）を MarkIts で再編集できるようにし、画像メニューに「画像に保存する」を追加しました。リッチ編集への通常貼り付け時もアセットフォルダーへ直接保存されるよう統一しました。
- **タブ切替・プレビュー・UI の磨き込み**: プロジェクト読込中のタブ切替応答を改善し、タブ選択時のプレビュー白フラッシュを解消しました。ドキュメント内検索（`Ctrl/Cmd+F`）、ファイルツリー検索トグル、タブのドラッグ並び替え・中クリック閉鎖・横スクロール、撮影リソース件数バッジ、通知トースト＋履歴、コンボボックスのフォーカス枠欠け修正、再読込・HTML出力アイコンの改善を行っています。

配布対象は Windows x64 です。
