# Munin Manual Studio 0.9.21

画像の表示設定と原稿の編集画面を改善しました。

- 画像の表示幅を「指定なし」にできるようになりました。配置とキャプションは個別に設定できます。
- 表示幅の横に「指定なし」ボタンを追加し、入力欄と高さ・位置を揃えました。
- Milkdownの編集画面では、スクリーンショットの管理用コメントを非表示にします。参照情報は原稿に保持され、Markdownソースでは確認できます。
- 再撮影テストの結果確認を画像IDで行うよう修正し、OSによる結果の並び順の違いでリリースが失敗する問題を解消しました。

Windows x64、Linux x64、macOS Intel／Apple Silicon向けZIPを配布します。
