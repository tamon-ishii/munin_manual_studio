# Munin Manual Studio 0.9.37

- **MkDocs / Zensical の仮想環境探索とワーキングフォルダ指定**:
  - プロジェクトが `.venv` / `venv` より下のサブフォルダー（または `.venv` 配下）をルートにしている場合でも、親フォルダーの `.venv` / `venv` や `CONDA_PREFIX` を自動探索して MkDocs / Zensical を見つけられるようにしました。
  - 「HTML出力」ダイアログと「設定 → HTML出力」に「ワーキングフォルダ（.venv 探索元・省略可）」設定とネイティブの「参照…」ボタンを追加し、入力欄がダイアログ幅いっぱいに広がるようレイアウトを修正しました。
  - MkDocs / Zensical が見つからないエラー時に、その場からワンクリックで「単一HTML（Python不要）で今すぐ作成」または「ワーキングフォルダを参照…」へ進めるリカバリ導線を追加しました。
- **実環境・Windows / サブフォルダー構成での堅牢化**:
  - Windows の `\\?\` 拡張パス混入による不具合、サブプロセス起動時のコンソール点滅（`CREATE_NO_WINDOW`）、PTY マルチバイト UTF-8 のチャンク境界文字化け、GUI 起動時の CLI パス検出漏れ、対象アプリ起動時の `.cmd`/`.bat`/引数・エラー出力処理を修正しました。
  - サブフォルダーをプロジェクトルートにした場合の親リンク（`../README.md`）による HTML 出力中断、単一HTML の見出しアンカー（`#fragment`）リンク、読者別出力での `index.md` 必須制約、`docs/ai/` や `site-user/` の誤判定、空フォルダーへの新規作成・`docs == "."` 構成・Windows 大文字小文字リネーム（ロック重複デッドロック解消を含む）を修正しました。
- **フロントエンド UX・エラー表示・設定同期の改善**:
  - 各モーダルダイアログへのインラインエラー表示、AI設定クローズ/終了時の保存フラッシュ、AIエラー案内からの「AI設定を開く」ボタン、履歴の個別削除、起動時の無効な前回プロジェクト履歴の自動クリアを追加しました。
  - AI協業ツール（初期サイズ 1040×760）で「読者保存」時に未保存の目次編集が消えないようにし、各パス入力欄への「参照…」ボタン、読者別出力の「出力HTMLを開く」ボタン、派生原稿ファイル名編集＋既存ファイル保護、翻訳同期の1ページ/同一ページガードを追加しました。

配布対象は Windows x64 です。
