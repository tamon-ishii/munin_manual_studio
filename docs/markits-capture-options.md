# MarkIts撮影の起動オプション

Manual Studioから撮影するときも、次の設定をMarkItsへ明示的に渡します。

```text
markits-desktop.exe --capture --include-cursor --capture-shortcut "Control+Shift+E"
```

- `--capture`: 撮影を開始する。通常はウインドウ選択画面を開く。
- `--include-cursor`: 撮影キーを案内する操作ウインドウを表示し、キーの入力を待つ。キーを押した時点のカーソル位置にあるウインドウを撮影する。
- `--no-cursor`: カーソルを含めない初期状態にする（指定なしの場合もオフ）。
- `--capture-shortcut <key>`: この起動で使う撮影キー。保存済みの既定キーは書き換えない。

カーソル付き撮影では、撮影キーとキャンセル操作を案内する操作ウインドウを表示します。OKで確認するダイアログは出しません。カーソルを撮りたい位置へ動かし、表示された撮影キーを押して撮影します。撮影が完了してからMarkItsの編集画面を表示します。撮影キーが別のアプリと競合する場合も、選んだキーを維持します。操作ウインドウに登録できない理由を表示し、競合解消後に同じキーで再登録できます。別のキーへ自動変更しません。

Manual Studioの「設定 → 撮影 → 新規撮影でカーソルを含める」で既定値を変更できます。撮影キーも同じタブで変更できます。
