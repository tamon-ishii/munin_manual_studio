# Munin Manual Studio 0.9.9

原稿編集・撮影・画像管理のUI改善と、Linuxビルドおよび実画面検証の修正を含む配布版です。

- フォルダ履歴のドロップダウンとキーボード操作。
- 原稿タブ・表示切替・保存状態の集約、保存再試行と外部変更の比較。
- 撮影するアプリの登録、画像の再撮影・更新をリソース一覧に集約。
- 選択範囲のAI編集とカーソル位置へのAI挿入を区別し、リッチ編集の選択状態を同期。
- 独立した執筆方針、原稿・フォルダ作成メニュー、未選択時の案内。
- 原稿チェックの独立。HTML生成は外部連携・CLIで実行できます。
- シンボリックリンクを含むプロジェクトの画像差し替え・復元を修正。
- 日本語の利用ガイド下書きを `manual_doc/` に追加。
- 画像生成ジョブのロックを明示的に解放し、中断した実行の復旧を安定化。
- Ubuntu WebKitの原稿入力欄のAT-SPIロール互換性を修正し、実際の撮影・挿入・保存・Undoとクリップボード操作を検証。
- CIの色付きCargoログに対応し、実際のMarkIts操作による変換エラーと原稿破壊の障害注入テストを修正。
- 撮影テストの失敗画面・アクセシビリティ情報をCI成果物に保存。

配布ZIPは展開後の配置を保持して起動してください。Markdown編集・手動撮影にAI設定は不要です。AI機能には接続設定、外部からのHTML生成にはMkDocsが必要です。
