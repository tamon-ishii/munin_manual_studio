# Munin Manual Studio 0.9.13

原稿は自動保存を停止し、保存ボタンまたは Ctrl/Cmd+S で保存する方式に変更しました。未保存の変更はタブの `*` で示し、タブ切り替え後も保持します。

- 原稿の自動保存を停止し、明示的な保存操作まで編集内容を保持します。未保存のままファイル移動などを実行する場合は、先に保存するよう案内します。
- リッチ編集とMarkdownソースの切り替え、保存、タブ移動でUndo履歴が失われる問題を修正しました。Undo／Redoは編集内容に対して動作します。
- AI修正案やスクリーンショット挿入の結果も、原稿へ反映した後に明示的に保存できます。
- GitHub Flavored Markdownのアラートを暗色テーマでも読みやすい配色に修正しました。エディターとプレビューの両方で確認しています。

Windows x64、Linux x64、macOS Intel／Apple Silicon向けZIPを配布します。
