## Why

MarkIts は高品質なセマンティック注釈（矢印、コールアウト、スポットライトなど）を生成する軽量な Rust ライブラリおよび CLI ツールですが、ユーザーが画面を直感的にキャプチャし、GUI 上でドラッグ＆ドロップによりアノテーションを配置・微調整して共有するデスクトップ環境は提供されていませんでした。
既存のライブラリや CLI の軽量性・単体提供を完全に維持しつつ、システムトレイ常駐で PrintScreen 等のキーから全画面・ウィンドウ・任意矩形キャプチャを起動し、矢印の端点ドラッグやフォント編集、さらには保存した PNG からの再編集までをシームレスに行えるデスクトップ GUI アプリケーションを提供します。

## What Changes

- **マルチクレート構成への拡張（単体提供の維持）**:
  - コアの `markits`（ライブラリおよび CLI）は外部 GUI 依存を持たない軽量な状態を維持。
  - Tauri 2.0 を採用したデスクトップアプリケーション（`apps/desktop`）を Cargo ワークスペースに追加。
- **システムトレイ常駐 & グローバルホットキー**:
  - システムトレイに常駐し、PrintScreen またはカスタムショートカットの押下を検知してバックグラウンドからキャプチャを起動。
- **マルチモード・スクリーンキャプチャ**:
  - Windows Snipping Tool のような半透明オーバーレイ UI を表示。
  - 全画面、ウィンドウ選択、マウスドラッグによる任意矩形範囲キャプチャに対応。
- **インタラクティブ・アノテーションエディタ**:
  - キャプチャ直後に編集画面が開き、MarkIts のマークを重ねて配置。
  - 矢印・ベジェ矢印の始点・終点・制御点などをマウスドラッグで直接編集可能。
  - ラベルやコールアウトのテキスト編集、フォントファミリー・フォントサイズ・セマンティックスタイルのリアルタイム調整。
- **クリップボード保存・ファイル保存・再編集メタデータ埋め込み**:
  - アノテーション付き画像をワンクリックでクリップボードへコピー、または PNG ファイルとして保存。
  - 保存する PNG のメタデータ（tEXt チャンク）に MarkIts のアノテーション JSON データを透過的に埋め込み、保存済み PNG をアプリで開くことでアノテーションを復元して再編集可能にする。

## Capabilities

### New Capabilities
- `desktop-app`: システムトレイ常駐、トレイメニュー、グローバルホットキー監視、ウィンドウライフサイクル管理
- `screen-capture`: 全画面・アクティブウィンドウ・任意矩形選択による画面キャプチャおよびオーバーレイUI
- `annotation-editor`: キャプチャ画像に対するインタラクティブなアノテーション編集（矢印の端点ドラッグ、テキスト/フォント/スタイル設定）
- `image-metadata`: PNG メタデータ（tEXt チャンク）への MarkIts JSON 埋め込み・抽出による再編集機能、クリップボード・ファイル入出力

## Impact

- **クレート構成**: Cargo ワークスペース化（`markits` コアクレートと `markits-desktop` Tauri アプリクレートに分離）。
- **依存関係**: デスクトップクレート側に Tauri 2.0、画面キャプチャ用ライブラリ（`xcap` 等）、PNG メタデータ操作ライブラリ、Web フロントエンド環境を追加。既存 `markits` クレートのフットプリントは一切増加しない。
- **互換性**: 既存の `markits` CLI コマンドや Rust API に後方互換性の破壊的変更はなし。
