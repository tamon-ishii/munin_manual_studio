# Proposal

## Why

複数原稿の修正と長い文書の整理に、全文検索・選択置換と見出し移動が必要。原稿の永続的な復元は独自履歴を増やさずGitのコミット履歴に統合する。

## What Changes

- Gitの利用状態、原稿の変更・コミット履歴・差分を表示し、選んだ版を確認して編集・保存経路へ復元する。既定は明示的な手動コミット。リモート操作は追加しない。
- プロジェクト内Markdownを全文検索し、該当箇所への移動、置換前の差分確認、選択した箇所だけの置換と取り消しを提供する。
- ATX・Setext見出しのアウトラインを表示し、本文への移動、同じ親・階層の節をドラッグまたは上下操作で並べ替える。
- すべての非同期操作で原稿・プロジェクトの所有権と更新競合を検証し、既存のUndo、原稿、画像参照を保護する。

## Capabilities

### New Capabilities

- `manuscript-git`: Gitを使った原稿のコミット・比較・復元。
- `manuscript-search`: 全文検索、選択置換、差分確認と置換の取り消し。
- `manuscript-outline`: 見出し一覧、移動、節の並べ替え。

### Modified Capabilities

なし。既存の保存・Undo・プロジェクト境界の契約を維持する。

## Impact

manual-coreのRPCとGit/検索/Markdown解析、manual-studioの機能別UIモジュールと既存保存経路、Rust・ブラウザー回帰テスト、操作ガイド。Git実行ファイルを利用し、新規依存ライブラリやリモートサービスは追加しない。
