# Upstream source

This standalone project contains Manual Studio and a source snapshot of MarkIts.

MarkIts upstream repository: https://github.com/tamon-ishii/markits

The MarkIts snapshot is based on upstream commit `2191406dab4c3ad895476a0f112bbc715cbf325a` (2026-10-03). The source checkout had local modifications when staged; the copied files preserve that working-tree state. The copy intentionally omits the upstream `.git` metadata and generated `node_modules`, `target`, `dist`, and Python cache directories. MarkIts copyright and license notices remain in `crates/markits/LICENSE` and the relevant source files.
